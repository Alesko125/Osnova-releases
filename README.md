# Osnova-tv — збірки застосунку

Тут лежать готові APK застосунку «Основа» для Android і файл, за яким сам
застосунок перевіряє, чи вийшла нова версія. **Вихідного коду тут немає** — він
у закритому репозиторії.

Останній випуск: [Releases](https://github.com/Alesko125/Osnova-releases/releases/latest)

## Навіщо окремий репозиторій

Застосунок роздається файлом, а не через Google Play, тому має перевіряти
оновлення сам. Раніше він ходив по це на власний сервер провайдера — і разом з
сервером лягали й оновлення. Тепер `version.json` і самі APK лежать тут, тож
перевірка працює незалежно від того, чи піднятий бекенд.

Код при цьому лишається закритим: сюди потрапляють лише файли, які і так
опиняються на телефоні в кожного абонента.

## version.json

Застосунок читає його за постійною адресою:

```
https://raw.githubusercontent.com/Alesko125/Osnova-releases/main/version.json
```

| Поле | Що означає |
|---|---|
| `version_code` | Ціле число. Застосунок пропонує оновитись, якщо тут число більше за його власне. |
| `version_name` | Що показати користувачеві («2.0»). |
| `apk_url` | Звідки завантажувати. Посилання на файл з релізу нижче. |
| `mandatory` | `true` — вікно оновлення не можна закрити. |
| `notes` | Короткий текст у вікні оновлення. |

Порядок випуску: створити реліз з APK → у `version.json` підняти `version_code`
і `version_name`, підставити посилання на новий файл. Поки `version_code` не
піднято, застосунки оновлення не побачать.

## Встановлення

Android блокує встановлення файлів зі сторонніх джерел, доки ви не дозволите
це браузеру чи файловому менеджеру, з якого відкриваєте APK. Потрібен
Android 8.0 або новіший.

Збірки підписані ключем розробника. Оновлення поверх ставиться лише якщо
попередню версію встановлено з таким самим підписом — інакше спершу треба
видалити стару.
